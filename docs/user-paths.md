## Defects

- D1 `save_settings` persists unvalidated settings: `commands.rs:159` -> `AppState::update_settings` `src-tauri/src/state.rs:142` never calls `AppSettings::validate` (`src-tauri/src/models.rs:23`); the only caller is `indexer.rs:70`, so an invalid value is written to disk and surfaces later as an indexing failure, not as a rejected save.
- D2 Backup and "Clear local index" are refused while indexing (`src-tauri/src/commands.rs:185`, `src-tauri/src/commands.rs:218`) but the UI has no pause control, so the user cannot satisfy the precondition — the only remedy is to wait out the whole index run.
- D3 "Ask about this and related files" (`src/App.tsx:583`) only switches the view; the selected chunk is dropped and `AskView` always sends `sourceIds: []` (`src/App.tsx:614`), so `redrob::ask` re-searches from the question text (`src-tauri/src/redrob.rs:113`). `bridge.ask` accepts the ids (`src/lib/bridge.ts:165`) and `get_sources` exists to resolve them — both unused.
- D4 `pause_indexing` is registered (`src-tauri/src/lib.rs:50`) and bridged (`src/lib/bridge.ts:153`) but has no UI entry point; the pause state it sets is fully implemented in the indexer (`src-tauri/src/indexer.rs:94`).
- D5 Two registered commands have no caller at all: `get_sources` (`src-tauri/src/lib.rs:52`, `commands.rs:124`) and `get_connection_status` (`src-tauri/src/lib.rs:56`, `commands.rs:179`) — dead IPC surface.
- D6 No frontend test exists anywhere: `package.json` declares no test runner for `src/` (`test:rust` only, `package.json:23`), so all 38 `code-only` rows above include every React handler and the whole bridge.
- D7 Extension filter tabs are computed from the current result set (`src/App.tsx:344-350`), so selecting `PDF` re-runs the search, the result set becomes PDF-only, and every other type's tab disappears — the user must return to `All` to reach another type.
- D8 `get_documents` is called with `limit: 250` (`src/lib/bridge.ts:189`) but only 12 rows render (`src/App.tsx:922`), and `offset` is never used: the command's pagination (`src-tauri/src/commands.rs:112`) has no UI, so the library is unbrowsable beyond 12 files.
- D9 A failed document's `lastError` (`src/types.ts:83`, populated by `Storage::mark_document_failed` `src-tauri/src/storage.rs:332`) is never rendered — the Sources table shows only "Failed" (`src/App.tsx:951`), and the "Needs attention" stat card (`src/App.tsx:855`) leads nowhere.
- D10 Updater download progress is dropped: `installPendingUpdate` takes an `onProgress` callback (`src/lib/bridge.ts:249`) and the only caller passes none (`src/App.tsx:1059`), so a multi-hundred-MB download shows one "Downloading…" toast that expires after 3.5 s.
- D11 "Check now" reports success even when nothing happened: `start_indexing` returns `Ok(false)` when an index is already running (`src-tauri/src/commands.rs:72`) and the UI ignores the boolean (`src/App.tsx:868`).
- D12 On Linux, "Show in folder" opens the containing directory without selecting the file (`src-tauri/src/commands.rs:152-156`), unlike the Windows/macOS branches which do select it.
- D13 Error toasts auto-dismiss after 3,500 ms with no manual dismiss and no log (`src/App.tsx:43-47`), so a long Rust error message from `readError` (`src/App.tsx:1675`) can be unreadable before it disappears.
- D14 The browser mock reports success for work it does not do — `chooseFolder` returns a hardcoded `/Users/you/Documents` (`src/lib/bridge.ts:133`), `startIndexing` returns `true` (`src/lib/bridge.ts:151`), `checkLibraryHealth` returns the real success sentence (`src/lib/bridge.ts:237`), `createBackup` returns a fake path (`src/lib/bridge.ts:233`). A UI review run in a browser therefore cannot distinguish a working app from a dead one.
- D15 In the browser mock the Ask flow cannot complete: `onSnapshot` is a no-op (`src/lib/bridge.ts:268`) so `snapshot.connection.connected` never becomes true after connecting, and `AskView`'s connect callback does not refresh (`src/App.tsx:718`) — pressing "Ask Redrob" reopens the connect modal indefinitely. On desktop the Rust `emit_snapshot` (`src-tauri/src/state.rs:174`) covers this.
- D16 `AppState::disconnect` swallows keyring deletion failures with `let _ =` (`src-tauri/src/state.rs:181`), so the UI reports "Redrob disconnected from this device" even when the stored credential survives.
